# Vidmody IPTV Proxy & Smart TV Movie Portal

Bu proje, Vidmody üzerindeki kamufle edilmiş video yayınlarını standart video formatlarına dönüştürerek Smart TV oynatıcılarında sorunsuz çalışmasını sağlar.

---

## 📺 Televizyonda Kullanım Rehberi

### 🛠️ Yöntem 1: SS IPTV ile İzleme
1. Harici Oynatma Listeleri (External Playlists) sekmesine gidin.
2. **Add Item** diyerek şu kaynak linkinizi ekleyin:
   * **Source:** `https://Yigit404-babam-sinema.hf.space/playlist.m3u`
3. Kaydedin. Artık televizyonunuzdaki SS IPTV uygulamasında tüm filmler oynatılacaktır!

### 🍿 Yöntem 2: Netflix Tarzı Premium Web Portalı
1. Smart TV'nizin kendi **İnternet Tarayıcısını** (Web Browser) açın.
2. Adres satırına şu adresi yazın:
   * `https://Yigit404-babam-sinema.hf.space`
3. Tarayıcıyı **Sık Kullanılanlara (Yer İmleri)** ekleyin.
4. Babanız kumandanın yön tuşlarını kullanarak tam ekran sinema kalitesinde film izleyebilir!
